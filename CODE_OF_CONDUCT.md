# Code of Conduct

## Our commitment

Abu AI welcomes contributions from people with different backgrounds, experiences, and levels of technical knowledge.

Project discussions should remain respectful, objective, and focused on improving the software.

## Expected behavior

Contributors are expected to:

* Communicate respectfully
* Accept constructive feedback
* Focus criticism on ideas and code
* Provide context when suggesting changes
* Respect different levels of experience
* Avoid unnecessary personal conflicts

## Unacceptable behavior

The following behavior is not accepted:

* Harassment or personal attacks
* Discriminatory or offensive comments
* Publishing private information without permission
* Deliberately disrupting discussions
* Repeatedly ignoring contribution guidelines
* Using issues or pull requests for unrelated promotion

## Project moderation

Project maintainers may edit, hide, or remove comments, issues, pull requests, and contributions that violate these guidelines.

Serious or repeated violations may result in temporary or permanent restrictions from participating in the project.

## Reporting

Conduct problems should be reported privately to the project maintainer instead of being discussed publicly in an issue.

Reports will be reviewed with discretion and only the necessary information will be shared.
